# Sentiment Analysis on Social Media Posts

NLP project that classifies social media posts as Positive, Negative, or Neutral using classic NLP preprocessing and machine learning, with an interactive Gradio demo.

## Tech Stack
Python · NLTK · Scikit-learn · TF-IDF · Naive Bayes · SVM · Gradio

## Highlights
- Text preprocessing: cleaning, tokenization, stop-word removal, and lemmatization.
- TF-IDF feature extraction.
- Trained and compared Multinomial Naive Bayes and Linear SVM classifiers.
- Exported the model with joblib and built an interactive Gradio interface.

## Repository Contents
- `nlp-project (2).ipynb`: full notebook
- `NLP Project Report.docx`: report
- `Sentiment Analysis.pptx`: presentation
- `sentiment_analysis.csv`: dataset
